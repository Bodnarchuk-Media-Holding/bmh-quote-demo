# BMH Quote Builder — PUBLIC STATIC DEMO

This public repository hosts only the standalone, non-production HTML demonstration. Prices are **illustrative and not approved quotations**. There is no shared quote backend, account login, payment processing, server-side persistence, or client data collection. Do not enter personal information.

Source staging application, private pricing, and collaboration backend remain in a separate PRIVATE repository, not published here. No credentials or actual customer files are included.
